# モデル規模軸: KV 量子化の効き方は規模に依存するか

> **データ裏付け: VERIFIED (8B は二重確認済) / TB_ONLY (4B)** — 本ファイルの数値は run `p2m_8b_bf16` / `p2m_8b_e4m3` / `p2m_8b_e5m2` (VERIFIED)、`h200_p4_calib` / `e4_c2_kv_e4m3` / `e4_c1_kv_e5m2` (TB_ONLY) の TensorBoard event file に
> 由来する。判定と引用可否の定義は同ディレクトリの `DATA_STATUS.md`、照合コマンドは
> `python3 verify_results.py` (Ray head pod)。数値を他の文書へ転記する前に必ず照合する。


問い: dense 4B で見えた「KV を fp8 にすると mis_kl が 1 桁以上増える」という効果は、
モデル規模を変えても同じか。これは「fp8 で崩壊しやすくなる」というリスク評価を
4B 以外に一般化してよいかを決める。

計測は 2026-08-03、p5en.48xlarge (H200) x2 の Capacity Block 上。
すべて step 0 のみ (NUM_ROLLOUT=1) で optimizer step を踏まないので、
測っているのは純粋な数値経路差である。

## 結論 (2 seed 時点、下記の 4 seed 結果で更新済み)

4B と 8B の 2 点で見ると:

| 精度 | max/min | CV (n=2) |
|---|---|---|
| bf16 | 1.19x | 12.1% |
| e4m3 | 1.12x | 7.7% |
| e5m2 | 1.26x | 16.2% |

**当初これを「fp8 の到達値はモデル依存」と読んだが、その解釈は成立しない。**
後から同一構成で 4 seed を取った結果 (`PP_POSITION_PROFILE.md`)、
この条件での seed 分散は以下だった。

| 精度 | seed CV (n=4) | seed max/min |
|---|---|---|
| bf16 | 7.8% | 1.19 |
| e4m3 | 11.3% | 1.26 |
| e5m2 | 10.7% | 1.27 |

**モデル間の差 (CV 7.7-16.2%、max/min 1.12-1.26) と seed 分散 (CV 7.8-11.3%、
max/min 1.19-1.27) はほぼ同じ大きさである。** つまり 4B と 8B の違いは、
同じモデルを別の seed で回したときの違いと区別できない。

なお当初「4B の seed 分散は 0.21-0.30%」と書いたのは誤りで、それは別条件
(collapse 実験の step 0) の値を流用したものだった。この構成の実測は上表の通り
1 桁以上大きい。

これは重要な訂正を含む。前セッションで「fp8 は mis_kl を量子化精度で決まる値に固定する
(モデルに依らず e4m3 なら 0.009、e5m2 なら 0.032)」と報告したが、**その主張は成立しない**。
根拠にした 8B の数値は実行されていないもので、実測すると 8B e5m2 は 0.0258 であり
0.032 ではなかった。

言えるのは、seed 分散より大きい効果に限られる:

1. **KV 量子化は mis_kl を 1 桁以上増やす。これは 4B と 8B の両方で成立**
   (e4m3 で 10-14 倍、e5m2 で 35-52 倍)。この 10-50 倍という効果は
   seed 分散 (1.2-1.3 倍) より 1 桁以上大きいので、明確に実在する。
2. **量子化精度に対する単調性は両モデルで成立** (bf16 < e4m3 < e5m2)。
   bf16 -> e4m3 -> e5m2 の各段が 3-4 倍ずつ動くので、これも seed 分散を超える。

**言えないこと**: 倍率がモデルによって変わるか (e5m2 で 34.6x vs 51.7x の差は
seed 分散と同オーダー)。これを主張するには各モデルで 4 seed 以上必要で、
2 点の点推定では判定できない。

したがってリスク評価に使えるのは **オーダー (1 桁増) と単調性**までである。
「約 N 倍」という具体的な倍率をモデル間で比較するには seed 複製が要る。

## 8B を 4 seed で測り直した結果: 判定が分かれた

当初は各モデル 1 seed の点推定しか無く、4B と 8B の差が seed 分散と同じ大きさだったため
「判定保留」とした。その後 8B も 4 seed 取得したので、**範囲どうしの比較**ができるように
なった。以下が 4 seed x 2 モデル x 3 精度 = 24 run の結果である。

| 精度 | model | 平均 | 範囲 (min - max) | seed CV | 範囲の重なり |
|---|---|---|---|---|---|
| bf16 | 4B | 0.000575 | 0.000527 - 0.000625 | 9.6% | **重ならない** |
| bf16 | 8B | 0.000718 | 0.000677 - 0.000745 | 4.1% | |
| e4m3 | 4B | 0.008149 | 0.007416 - 0.009360 | 11.3% | **重なる** |
| e4m3 | 8B | 0.007008 | 0.006013 - 0.007755 | 10.5% | |
| e5m2 | 4B | 0.029509 | 0.025995 - 0.032907 | 10.7% | **重ならない** |
| e5m2 | 8B | 0.023437 | 0.020671 - 0.025758 | 9.5% | |

**精度によって判定が分かれる。** これは当初の「モデル依存」でも、訂正後の
「区別できない」でもない、第三の結果である。

1. **bf16 では 8B のほうが高い。** 4B の最大 0.000625 < 8B の最小 0.000677 で範囲が
   完全に分離する。分布の仮定を置かずに「8B の数値経路差は 4B より大きい」と言える。
2. **e5m2 では 8B のほうが低い。** 4B の最小 0.025995 > 8B の最大 0.025758 で、
   こちらも (わずかだが) 分離する。粗い量子化では 8B のほうが mismatch が小さい。
3. **e4m3 では重なる。** 4B [0.00742, 0.00936] と 8B [0.00601, 0.00776] が交差するので、
   この精度ではモデル間差を主張できない。

したがって「fp8 の到達値はモデルに依存するか」への答えは **精度による**。
bf16 と e5m2 では依存が検出でき、e4m3 では検出できない。

倍率で見ると方向が揃う。8B は bf16 baseline が高く fp8 到達値が低いので、
**倍率は一貫して 8B のほうが小さい** (e5m2 で 4B 51.3 倍に対し 8B 32.6 倍)。
ただし倍率は分子と分母の両方に分散が乗るので、範囲の非重なりで確認した上記 2 点
(bf16 と e5m2 の水準差) のほうが根拠として強い。

**実務的な含意**: 「モデルを変えたら mis_kl の水準も変わる」ので、リスク評価の
閾値をモデル間で流用してはいけない。ただし変化はどちらの向きにも 1.3 倍程度で、
量子化そのものの効果 (10-50 倍) とは 1 桁違う。**量子化の効果はモデルを超えて
移植できるが、絶対値の閾値は移植できない。**

## chi2_token: 裾も同じオーダーで動く

| model | bf16 | e4m3 | e5m2 |
|---|---|---|---|
| 4B | 0.001281 | 0.020269 | 0.077630 |
| 8B | 0.001433 | 0.015079 | 0.084762 |

分散に敏感な `mis_chi2_token` も mis_kl と同じオーダーで動いており、
「平均は小さいまま裾だけが暴れる」パターンではない。

## grad_norm と reward

| model | 精度 | grad_norm | reward |
|---|---|---|---|
| 8B | bf16 | 0.0745 | 0.453 |
| 8B | e4m3 | 0.0992 | 0.422 |
| 8B | e5m2 | 0.3377 | 0.422 |

grad_norm は e5m2 で 4.5 倍になる。step 0 なので学習はしていないが、
勾配の大きさが量子化で変わることは、長い学習で挙動が分岐する経路を示唆する。
reward は 0.45 -> 0.42 で、step 0 の 128 サンプルでは有意差とは言えない。

## 限界

- 各セルは単一 run の点推定である。同一構成の 4B で後から 4 seed を取った結果、
  この条件の seed 分散は CV 7.8-11.3% だった (`PP_POSITION_PROFILE.md`)。
  8B は 1 seed のみなので、8B 側の分散は未測定である。
  **モデル間差を主張するには両モデルで seed 複製が必要**で、それが本表の最大の限界である。
- 4B は TP1、8B は TP2 で測っている。P1 で並列構成が mis_kl に与える影響は
  1.21 倍の範囲内と確認済みなので、TP1 vs TP2 の差 (P1 実測で +3.3%) は
  モデル間差 (19-26%) より小さく、結論を変えない。ただし完全な apple-to-apple ではない。
- 30B MoE は計測不能だった。生成が反復ループに陥り (repetition_frac 0.63、reward 0.0、
  mis_ppl_ratio 1.78)、mis_kl が量子化ではなく反復を測ってしまう。応答長・重み一致・
  温度・モデルファイルの 4 仮説をすべて実測で否定したが原因は未特定
  (`P2R_30B_INVALID.md`)。したがって本軸は 2 点であり、「規模に対する傾向」は言えない。
  言えるのは「4B と 8B で倍率が異なる」ことまでである。
