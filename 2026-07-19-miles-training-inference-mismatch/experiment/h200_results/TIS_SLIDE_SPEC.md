## 図1: T^2 bound と実測 trajectory

### 軸設計

| 項目 | 値 |
|---|---|
| 横軸 | training step (0-30) |
| 縦軸 | mis_kl (**log scale 必須**、0.01-100) |

### 描画する系列

| # | 系列 | スタイル | データ |
|---|---|---|---|
| 1 | TIS off 実測 | 赤・実線 | step 0: 0.032, step 8: 0.072, step 14: 0.399, step 18: 1.659, step 24: 11.03, step 29: 31.78 |
| 2 | TIS on 実測 | 青・実線 | max 0.056, 30 step 完走。first=0.032, last=0.028 |
| 3 | 理論 O(T^2) | 赤・破線 | `mis_kl(T) = 0.035 * T^2` (端点フィット: 31.78/30^2 = 0.035) |
| 4 | 理論 O(T) | 青・破線 | `mis_kl(T) = 0.005 * T` |
| 5 | 3-seed バンド | 半透明帯 | TIS off: 全3seed崩壊、TIS on: max 0.15 |

### callout

- A (系列1の曲がる箇所): 「勾配経由の正のフィードバックで epsilon の単純和を超える」
- B (系列2の横): 「cap=2.0 が各 step の寄与を制限 → 累積 O(T)、ほぼ平坦」
- C (30 step 終端): 「epsilon T^2 の epsilon (0.035) = step 0 の mis_kl (0.032) とほぼ一致。1 step 分の mismatch が T^2 倍に化けた」

### 正直な注記 (スライド上にも)

- 中間 step のデータは blog テーブル (6 点) からの補間。全 step の CSV は FSx の TensorBoard に残っているが、このスライドでは代表 step のみ使用。
- 端点 2 点フィットは illustrative。T^2 が成立する条件 (論文の定理の仮定) は別途確認必要。

## 図3: 処理フロー (5 ボックス)

```
┌───────────┐   ┌──────────────┐   ┌────────────────┐   ┌──────────────┐   ┌──────────┐
│ 1. rho 計算│──▶│ 2. cap       │──▶│ 3. veto        │──▶│ 4. normalize │──▶│ 5. loss  │
│           │   │ (truncate)   │   │ (RS)           │   │ (batch)      │   │          │
│ r = log   │   │ rho > 2.0    │   │ 系列内に        │   │ 生き残った    │   │ PG loss  │
│  pi_train │   │  → rho = 2.0 │   │ rho < 1e-4 が  │   │ rho を       │   │ に掛ける  │
│ - log     │   │              │   │ 1つでもあれば   │   │ mean=1.0 に  │   │          │
│  pi_roll  │   │              │   │ 系列ごと drop   │   │              │   │          │
│ rho=exp(r)│   │              │   │                │   │              │   │          │
└───────────┘   └──────────────┘   └────────────────┘   └──────────────┘   └──────────┘
```

### 具体例 (数値を流す)

入力: `rho = [0.8, 3.5, 1.2, 0.00003, 1.0]`

| 段階 | 状態 | 説明 |
|---|---|---|
| 1. 計算後 | [0.8, 3.5, 1.2, 3e-5, 1.0] | rollout と trainer の食い違いがそのまま重みに |
| 2. cap 後 | [0.8, **2.0**, 1.2, 3e-5, 1.0] | 3.5→2.0。上方向の爆発を止める |
| 3. veto | **系列ごと drop** | 3e-5 < 1e-4。信用できない系列を捨てる |
| 4. normalize | (この系列は drop 済み) | 残った系列群を mean=1.0 に |
| 5. loss | 使われない | drop された系列は勾配に寄与しない |

### 3 枚を貫くメッセージ (帯として)

> **「上は cap (2)、下は veto (3)、歪みは normalize (4) で戻す」— この 3 点セットで per-step epsilon を有界化し、累積を T^2 → T に落とす。**

## 確認事項 (登壇チームへ)

1. **中間 step の mis_kl CSV**: FSx の TensorBoard に全 30 step 分残っている。全点プロットにするなら次回 CB で抽出可能
2. **tis_lower_bound 0.5**: mode=truncate では upper のみ適用。lower は clip/mask mode 用。「本設定では L5 は使われていない」と言うのが正確
3. **veto による drop 率**: 実測値が未集計。次回 CB で `rs_catastrophic_seq_fraction` を TensorBoard から読めば取得可能
4. **T^2 bound の定理番号**: arXiv:2602.01826 の Section 何・Theorem 何かを原典で確認してスライドに引用
